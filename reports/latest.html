GET /documents/{id} Verified and Hardened

Root cause

Missing object-level authorization: get_document returned any document by ID after only authentication via require_user, without verifying doc.owner == authenticated user, allowing IDOR across alice/bob resources.

Evidence

  • EXPLOIT (non-owner bob): GET /documents/101 as bob -> 200, body shows owner alice
  • EXPLOIT (non-owner alice): GET /documents/202 as alice -> 200, body shows owner bob
  • CONTROL (owner alice): GET /documents/101 as alice -> 200 (owner access works)
  • CONTROL (owner bob): GET /documents/202 as bob -> 200 (owner access works)
  • DENIED (unauthenticated): GET /documents/101 as unauthenticated -> 401 (access denied)

PUT /documents/{id} Verified and Hardened

Root cause

Handler only verified authentication via require_user but never checked resource ownership against DOCUMENTS[id].owner, allowing any authenticated user (non_owner) to overwrite another user's document in violation of write: non_owner=deny.

Evidence

  • EXPLOIT (non-owner bob): PUT /documents/101 as bob -> 200, body shows owner alice
  • EXPLOIT (non-owner alice): PUT /documents/202 as alice -> 200, body shows owner bob
  • CONTROL (owner alice): PUT /documents/101 as alice -> 200 (owner access works)
  • CONTROL (owner bob): PUT /documents/202 as bob -> 200 (owner access works)
  • DENIED (unauthenticated): PUT /documents/101 as unauthenticated -> 401 (access denied)
